# B3 rendered screenshot evidence

54 actual-game captures. All measured game frames retain the 240×160 native composition; every capture has zero nonuniform native-pixel blocks. All B3 scene/UI captures have zero intermediate colors against the authored battle/world palettes and canonical UI palette. The unchanged B2 VS artwork is checked for pixel blocks but excluded from the B3 palette histogram. Every filename below is backed by its `battle*-captures.json` record in this same folder.

DPR 3 evidence uses 320×214 CSS and 4× physical scale, deliberately nondivisible by DPR. Black letterbox and transparent physical padding are preserved.
