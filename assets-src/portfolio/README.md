# Original B4 portfolio artwork

`build.py` authors integer cells and exports PNG/RLE pairs. No external reference images,
Nintendo/Game Freak sprites, brand logos or web icon library are used.

- 18 sixteen-pixel category/inventory emblems, their 32px integer-cell versions, and nine
  dedicated 8px category badges.
- One original 48×64 Trainer Card portrait, matching Uttkarsh's established teal jacket.
- Twelve 48×48 project treatments derived with explicit nearest-cell sampling from our own
  approved B3 emblems. B3 sources and assets remain unchanged.

The Pokédex uses enlarged category emblems as its permitted type-badge fallback; these are
not claims to individual technology brand logos. Full category names remain semantic text;
compact visual type labels are LANG, BACK, DIST, DATA, CLOUD, OPS, OBS, APP and IDEA.

UI borders, typography and cursors still come from canonical kit tokens and Raster. Artwork
colors are flat original palettes; there is no intermediate-color resampling.
